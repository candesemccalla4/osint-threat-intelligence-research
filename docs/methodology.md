# OSINT Investigation Methodology

## Project Overview

This project demonstrates the use of Open-Source Intelligence (OSINT) techniques to collect, analyze, and document publicly available cybersecurity information.

The objective of this investigation was to identify digital footprints, analyze infrastructure relationships, collect Indicators of Compromise (IOCs), and develop a structured threat intelligence assessment.

---

# Research Objectives

The investigation focused on:

- Identifying domain information
- Analyzing DNS records
- Reviewing IP address information
- Collecting indicators of compromise
- Documenting cybersecurity risks
- Developing threat intelligence recommendations

---

# Investigation Workflow

## Phase 1: Data Collection

Collected publicly available information including:

- Domains
- IP addresses
- DNS records
- Metadata
- Digital footprints


## Phase 2: Information Analysis

Analyzed collected information using:

- WHOIS lookup
- DNS resolution
- IP analysis
- IOC classification


## Phase 3: Threat Assessment

Findings were evaluated to determine:

- Potential risks
- Infrastructure relationships
- Security recommendations
