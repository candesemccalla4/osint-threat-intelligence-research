# Cyber Threat Assessment Report

## Project Title

Open-Source Intelligence Cyber Threat Investigation


## Author

Candese McCalla


## Introduction

This report documents an OSINT-based cybersecurity investigation focused on collecting and analyzing publicly available intelligence.


## Methodology

The investigation used:

- WHOIS analysis
- DNS investigation
- IP information gathering
- IOC analysis
- Python automation


## Tools

- Python
- Maltego
- SpiderFoot
- Shodan
- WHOIS


## Findings

The investigation identified relationships between domains, IP addresses, and other digital indicators.


## Risk Analysis

The collected information was evaluated to identify possible security risks and exposure points.


## Recommendations

Recommended security improvements include:

- Continuous monitoring
- Threat intelligence integration
- Asset inventory management
- Security awareness training


## Conclusion

This project demonstrates how OSINT techniques can support cyber threat intelligence operations and security decision-making.
